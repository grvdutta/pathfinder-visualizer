# Path Finder Visualizer

An interactive pathfinding visualizer built using HTML, CSS, and JavaScript to demonstrate graph traversal algorithms like BFS and DFS.

## Features

- Interactive grid
- Add start and end nodes
- Create walls/obstacles
- BFS shortest path visualization
- DFS traversal visualization
- Step-by-step animation

## Algorithms Implemented

### Breadth First Search (BFS)
- Guarantees shortest path in unweighted graphs
- Uses queue data structure
- Time Complexity: O(V + E)

### Depth First Search (DFS)
- Traverses deeply before backtracking
- Uses recursion or stack
- Time Complexity: O(V + E)

## Tech Stack

- HTML
- CSS (Grid Layout)
- JavaScript
- Graph Data Structure
